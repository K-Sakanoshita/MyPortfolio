01 / Works

プロジェクト

地域を歩いて得た情報をOpenStreetMapやWikimediaなどのオープンな基盤へ記録し、Webアプリ、教育、地域活動へ活用しています。

  • まち歩きマップメーカー ↗

    地域を歩いて得た発見を、誰でも書き込み、伝えられるように。自由に加工・利用できる地図画像をブラウザで作成するツールです。

    Map utility / 2020— / JavaScript · MapLibre

  • 遊具のある公園マップ ↗

    OpenStreetMapとWikimediaに蓄積された遊具の情報を、親子のお出かけに活かす地図。ブランコやすべり台など、遊具の種類から公園を探せます。

    Park map / OSM · Wikimedia

  • OSM What’s New Japan ↗

    日本のOpenStreetMapで「どこが、どう変わったか」を可視化。共同編集の積み重ねを見える形にし、地域の発見や次の調査・改善につなげます。

    Data visualization / 2026 / JavaScript · PHP · MariaDB

  • 少し昔の地図を見てみよう ↗

    過去のOpenStreetMapと現在の地図を見比べながら、まちや地域がどのように変化してきたかをたどれます。

    History map / Japan / OpenStreetMap · Open data

  • 万博マニアックマップ ↗

    大阪・関西万博をもっと深く楽しむための、会場内外の個性的な見どころを集めたプロジェクト。開催期間中の発見と体験を共有しました。

    Past project / 2025 / Open data · Community

  • 大阪思い出のこしマップ ↗

    個人の中にある大阪の思い出を、みんなでたどれる地域の記録へ。市民の記憶を地図の上に残し、場所とともに次へ読み継ぐプロジェクトです。

    Memories / Osaka / Open data · Community

  • 長浜城下町遺産マップ ↗

    市民が見つけた城下町の面影を「長浜城下町遺産」として紹介。地域の歴史を歩いてたどれるWebマップです。

    Local heritage map / OSM · Community

02 / Development

開発ツール

オープンデータを見つけ、確かめ、活用するための道具です。

  • Easy Changeset Viewer ↗

    OpenStreetMapの編集履歴を、地図を見ながら手軽に確認できるビューア。複雑な変更セットを直感的に読み解きます。

    OSM tool / 2021— / JavaScript · OSM API

  • コミュニティマップメーカー ↗

    OpenStreetMapとGoogleスプレッドシートを組み合わせ、地域団体が低コストで育てられるWebマップ開発フレームワーク。万博マニアックマップや十三アートフェスマップなどに活用されています。

    Framework / 2024— / OSM · Google Sheets

  • Japan PMTiles ↗

    APIキーや回数課金なしで日本地図を表示できる、開発者向けPMTilesデータとMapLibreのサンプルコードを配布しています。

    Map data / Japan / PMTiles · MapLibre

その他の開発

  • MuPLAY ↗

    MSXturboR向けに開発した、MGS・MPKなどに対応するマルチミュージックプレイヤー。

    MSX software / 1998–2000

  • DOL_CookingRecipe ↗

    「大航海時代 Online」の調理レシピを、レシピ帳や材料から検索できるツール。

    Game utility / 2010—

04 / Community

プロフィール・コミュニティ

坂ノ下 勝幸 / Katsuyuki Sakanoshita

オープンデータ実践者。OpenStreetMapを中心に、地域の情報を誰もが利用できる形で残す活動を続けています。

  • 大阪情報コンピュータ専門学校 講師
  • OpenStreetMap Foundation Japan 副理事
  • Code for OSAKA 理事
  • Wikimedians of Japan User Group

  • OpenStreetMap Japan

    誰もが使い、編集できる自由な地図を、日本の利用者や地域コミュニティとともに育てています。

    Web / Discord

  • OpenStreetMap Foundation Japan

    カンファレンスの開催やサーバー運用などを通じて、日本のOpenStreetMapコミュニティを支えています。

  • Wikimedians of Japan User Group

    日本語版ウィキメディア・プロジェクトの発展と、参加者が安心して活動できる環境づくりに取り組んでいます。

  • 諸国・浪漫

    地域の人自身が情報を記録し、発信する文化を各地に根づかせるための活動を続けています。

  • Code for OSAKA

    ITやオープンデータを活かし、市民の手で大阪のまちの課題に向き合うシビックテック・コミュニティです。

  • 淀川アートネット

    十三を中心に、文化活動を応援しながら人や店をつなぎ、アートでまちを盛り上げています。

  • Code for Kusatsu

    ICTを活用し、みんなが住み続けたいと思える草津のまちづくりを進めるコミュニティです。
